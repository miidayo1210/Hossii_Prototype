Hossiiの投稿画面で、写真・お絵描きを扱うときの **端末側の保存可否** と、カメラ撮影前の注意UIを定義する。

---

## 不変条件

1. Web（特に iOS Safari）では、`<input type="file" capture>` で撮った写真を **Camera Roll へ自動保存できない**。
2. ユーザーにはその制限を、撮影フローの手前で案内する。
3. お絵描きは端末に元データが無いため、完了時に共有／ダウンロード導線（`saveImageLocally`）を出してよい。
4. ギャラリーから選んだ既存写真は、すでに端末にあるため追加のローカル保存処理は不要。

---

## 投稿フォームのメディア導線

| ボタン | 動作 |
|--------|------|
| 🖼️ 写真を添付 | `accept="image/*"`（`capture` なし）。ライブラリ等から選択 |
| 📷 写真を撮る | 注意モーダル（未 dismiss 時）→ `capture="environment"` の file input を開く |
| ✏️ お絵描き | DrawingModal。完了時に `saveImageLocally()` |

### 撮影前注意モーダル（`CameraCaptureNoticeModal`）

- 文言: `Safariの制限上、ここで撮影した画像は端末に保存されません。`（`CAMERA_CAPTURE_NOTICE_TEXT`）
- **わかった** … モーダルを閉じ、同一ユーザー操作内でカメラ input を `click()`（iOS のジェスチャ制約に合わせる）
- **今後表示しない**（小さめ）… `localStorage` キー `hossii.cameraCaptureNotice.dismissed` = `1` を書き、以降は注意を出さずすぐカメラへ
- オーバーレイタップでキャンセル（撮影しない）

### 制限・既知の注意

- iOS の「写真を添付」でも OS シートに「写真を撮る」が出る場合がある。その経路ではアプリ側の注意モーダルは出せない（OS UI のため）。明示の「写真を撮る」ボタンが正本の撮影導線。

---

## 保存ロジック

### カメラ撮影（PostScreen）

- **端末アルバムへの自動保存は行わない**（制限どおり）。
- 以前の `lastModified` ヒューリスティック + `saveImageLocally` は投稿写真では廃止。

### お絵描き（DrawingModal）

1. `navigator.canShare({ files })` が使える場合 → Web Share API
2. 非対応 → `<a download>`
3. キャンセル／失敗しても投稿フローは止めない
